Configuration Hierarchy

Start broad, then override only the binding that differs.

ScopePrefixUse
All bindingsspring.cloud.stream.default.*Shared defaults such as content type.
All consumers/producers...default.consumer.* / ...default.producer.*Shared directional behavior.
One binding...bindings.<name>.*Destination, group, binder, or local override.
Binder extension...kafka.bindings.<name>.*Transport-specific feature.
 
spring:
  cloud:
    stream:
      default:
        consumer:
          max-attempts: 3
      bindings:
        inventoryConsumer-in-0:
          destination: inventory-events
          group: inventory-service
          consumer:
            max-attempts: 5

The named binding's max-attempts: 5 overrides the consumer default of 3.
