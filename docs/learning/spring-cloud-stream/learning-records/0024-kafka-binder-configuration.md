# Kafka Binder Configuration

The user studied the Kafka binder's three configuration namespaces: `kafka.binder.*` (binder-wide), `kafka.bindings.<name>.consumer.*` (per-consumer), and `kafka.bindings.<name>.producer.*` (per-producer), plus the `kafka.default.consumer/producer.*` defaults. The user reviewed key binder-wide defaults (`autoCreateTopics=true`, `autoAddPartitions=false`, `minPartitionCount=1`, `replicationFactor=-1`), the three client-property maps (`configuration` filters unknowns, `consumerProperties`/`producerProperties` allow them), the critical topic-provisioning failure mode (existing topic with fewer partitions than expected + `autoAddPartitions=false` → startup failure), consumer essentials (`autoRebalanceEnabled`, `ackMode` replacing deprecated `autoCommitOffset`, `startOffset` defaults: named group=earliest, anonymous=latest, `enableDlq`), and producer essentials (`messageKeyExpression`, `sync`, `compression`, `useTopicHeader`). A companion reference document with the full property table was created at `reference/kafka-binder-configuration.html`.
