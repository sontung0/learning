Reference Channel Interceptors

Channel Interceptors

Quick-reference for ChannelInterceptor, global interceptors, and wire tap.

ChannelInterceptor interface

public interface ChannelInterceptor {

    // ── Send lifecycle ─────────────────────────────────────
    Message<?> preSend(Message<?> message, MessageChannel channel);
    void postSend(Message<?> message, MessageChannel channel, boolean sent);
    void afterSendCompletion(
            Message<?> message, MessageChannel channel, boolean sent, Exception ex);

    // ── Receive lifecycle ──────────────────────────────────
    boolean preReceive(MessageChannel channel);
    Message<?> postReceive(Message<?> message, MessageChannel channel);
    void afterReceiveCompletion(
            Message<?> message, MessageChannel channel, Exception ex);
}

Veto behaviour

MethodReturn value to veto
preSendReturn null → cancels the send; postSend fires with sent=false
preReceiveReturn false → cancels the receive

Attaching interceptors

Per-channel (Java config)

DirectChannel channel = new DirectChannel();
channel.addInterceptor(myInterceptor());

Global interceptor

@Bean
@GlobalChannelInterceptor(patterns = "input*", order = 3)
public ChannelInterceptor loggingInterceptor() {
    return new ChannelInterceptor() {
        @Override
        public Message<?> preSend(Message<?> message, MessageChannel channel) {
            log.info("[{}] sending: {}", channel, message.getPayload());
            return message;
        }
    };
}
AttributeDescriptionDefault
patternsComma-separated globs ("input*, !cat*" to exclude)"*" (all channels)
orderExecution order (ascending)Lowest precedence

WireTap

// Copy messages to auditChannel without affecting the primary flow
@Bean
@GlobalChannelInterceptor(patterns = "orders")
public WireTap ordersWireTap(MessageChannel auditChannel) {
    return new WireTap(auditChannel);
}

DSL wire tap

@Bean
public PollableChannel myChannel() {
    return MessageChannels.queue()
            .wireTap("loggingFlow.input")
            .get();
}

Execution order

  1. Global interceptors (@GlobalChannelInterceptor) — sorted by order ascending
  2. Channel-specific interceptors (addInterceptor())
  3. Message dispatch to subscriber(s)
  4. postSend fires with the result
  5. afterSendCompletion fires (always)

Send lifecycle diagram

send() called
  └→ preSend()      ← return null to veto
      └→ dispatch to subscriber(s)
          └→ postSend(sent=true|false)
              └→ afterSendCompletion()  ← always fires

Custom ChannelInterceptorWireTap
