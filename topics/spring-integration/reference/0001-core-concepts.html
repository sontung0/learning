Core Concepts & Glossary

The compressed vocabulary of Spring Integration. Every later lesson assumes these terms. Keep this open.

The three nouns

TermOne-liner
MessagePayload (any object) + headers (metadata). The unit that flows.
ChannelThe pipe. Decouples producer/consumer; point of interception & monitoring.
EndpointThe filter. Connects your POJO to the messaging system non-invasively.

Channel dimensions

AxisOptionsMeaning
Deliverypoint-to-point / publish-subscribeone consumer per message vs. broadcast to all subscribers
Consumptionsubscribable / pollablemessage-driven (push) vs. buffered queue read by a poller (pull)

The seven endpoint types (Overview list)

EndpointJob
TransformerConvert payload/structure or modify headers.
FilterBoolean test — pass the message on, or drop/throw.
RouterDecide which channel(s) receive the message next.
SplitterOne message in → many messages out.
AggregatorMany messages in → one out (stateful: correlation + release + timeout).
Service ActivatorInvoke a service method; optional reply channel / return address.
Channel AdapterInbound/outbound bridge between a channel and an external system/transport.

Wiring cheatsheet

// Register infrastructure (Boot's integration starter does this for you)
@EnableIntegration

// A POJO service activator — no Message/Channel types leak in
@ServiceActivator(inputChannel = "in")
public String handle(String payload) { ... }

// Pull a header without exposing the Message type
@ServiceActivator(inputChannel = "in")
public String handle(@Payload String p, @Header("locale") String locale) { ... }

Glossary

TermDefinition
EIPEnterprise Integration Patterns — the Hohpe/Woolf catalogue Spring Integration implements.
Pipes-and-filtersArchitecture where "filters" (endpoints) process data and "pipes" (channels) connect them.
PayloadThe business object carried by a message.
HeadersMessage metadata: id, timestamp, correlationId, return address, plus custom key/values.
Return addressHeader naming the channel to send a reply to when no output channel is configured.
PollerScheduled task that reads messages from a pollable channel / source.
Service ActivatorGeneric endpoint connecting a service method to the messaging system.
Channel AdapterInbound/outbound endpoint bridging a channel to an external system.
ESBEnterprise Service Bus — the centralized hub model Spring Integration deliberately avoids.
@EnableIntegrationRegisters framework infrastructure beans (errorChannel, taskScheduler, annotation processors).
MessageChannelCore interface for channels (org.springframework.messaging).
MessageHandlerInterface every processing/outbound EIP component implements.
AbstractEndpointBase for consumers: EventDrivenConsumer (subscribable) / PollingConsumer (pollable).
SubscribableChannelPush-based channel: handlers subscribe; sender dispatches directly.
PollableChannelPull-based channel: consumer calls receive() to get the next message.
EventDrivenConsumerEndpoint that subscribes a MessageHandler to a SubscribableChannel.
PollingConsumerEndpoint that polls a PollableChannel via a scheduler-driven poller.
Push modelSender initiates delivery to subscriber(s) — SubscribableChannel.
Pull modelConsumer requests the next message when ready — PollableChannel.
ChannelInterceptorStrategy interface with hooks for intercepting send and receive operations on a MessageChannel.
preSendChannelInterceptor hook — fires before dispatch; return null to veto the send.
postSendChannelInterceptor hook — fires after dispatch with sent=true/false.
afterSendCompletionChannelInterceptor cleanup hook — fires on success or exception; not called when preSend returned null.
preReceiveChannelInterceptor hook — fires before receive; return false to veto.
postReceiveChannelInterceptor hook — fires after a message is received; can modify it.
afterReceiveCompletionChannelInterceptor cleanup hook — always fires after a receive completes.
@GlobalChannelInterceptorAnnotation that applies a ChannelInterceptor bean to all channels matching a name pattern.
Wire TapPattern where a ChannelInterceptor copies messages to a secondary channel for monitoring/auditing without affecting the primary flow.
WireTapSpring Integration's read-only interceptor class that implements the wire tap pattern.
MessagingTemplateImperative API in org.springframework.integration.core for programmatic send/receive/sendAndReceive against channels.
send(MessageChannel, Message)MessagingTemplate method — fire-and-forget; returns true on success, false on timeout.
receive(PollableChannel)MessagingTemplate method — pulls next message; returns null on empty queue / timeout.
sendAndReceive(MessageChannel, Message)MessagingTemplate method — request-reply with a temporary anonymous reply channel; blocks until the reply arrives.
Datatype ChannelA channel that restricts accepted payload types via setDatatypes(Class…); auto-converts using @IntegrationConverter if registered.
FailoverDirectChannel dispatcher behaviour: when enabled (default), tries the next handler if one throws; when disabled, the exception propagates immediately.
ExecutorChannelPoint-to-point channel that dispatches to each handler on a thread from the provided TaskExecutor — send() returns before the handler runs.
applySequenceFlag on PublishSubscribeChannel that injects sequenceNumber / sequenceSize headers per subscriber copy; required upstream of aggregators/resequencers.
Bounded QueueA QueueChannel created with a fixed capacity — send() returns false when full (after timeout); prevents unbounded memory growth.
