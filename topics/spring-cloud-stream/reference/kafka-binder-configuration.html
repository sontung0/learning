Prefix spring.cloud.stream.kafka.binder.* unless noted. Portable properties (destination, group, content-type, etc.) live under spring.cloud.stream.bindings.* — see core docs.

Partition Count Logic (Important!)

The binder uses the maximum of minPartitionCount and producer partitionCount as the target partition count when provisioning a topic.
  • Existing topic, fewer partitions than target + autoAddPartitions=false (default) → binder fails to start
  • Existing topic, fewer partitions + autoAddPartitions=true → new partitions added
  • Existing topic, more partitions than target → existing count used (no shrinkage)
