Content Type Negotiation

Choose the conversion path deliberately.

Content typeProvided converterTypical handler payload
application/json (default)JSON converterPOJO
text/plainObject/String converterString
application/octet-streamByte-array converterbyte[]
 
spring:
  cloud:
    stream:
      bindings:
        inventoryConsumer-in-0:
          content-type: application/json
          consumer:
            use-native-decoding: false

Native decoding bypasses Spring Cloud Stream message conversion; content-type then does not drive inbound conversion.
